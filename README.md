# HAIDER — بنية المشروع

```
index.html        الهيكل فقط (HTML دلالي: header / nav / main / footer)
css/styles.css    كل الأنماط، مقسّمة بتعليقات بنفس ترتيب الـcascade الأصلي
js/boot.js        يعمل في <head>: تطبيق الثيم قبل الرسم + تحميل الخطوط دون حجب
js/app.js         المنطق (أقسام معزولة بـ try/catch) + معالجات الأحداث المفوّضة
assets/avatar.jpg الصورة الشخصية (كانت مضمّنة مرتين كـ base64)
```

## ملاحظات مهمة
- **CSP:** أُزيل `'unsafe-inline'` من `script-src`. لا تضف `onclick="..."` ولا `<script>` مضمّنًا؛ استخدم `data-*` ومعالجًا في `app.js`.
- **Supabase:** المفتاح العام داخل `app.js` مقصود، وحمايته الفعلية من سياسات RLS في لوحة Supabase. راجعها: القراءة للعامة، والكتابة للأدمن فقط.
- **sw.js:** لو بيعمل cache للملفات، ارفع رقم نسخته وأضف `css/styles.css` و`js/*.js` و`assets/avatar.jpg`.
- **ترتيب الأنماط:** `css/styles.css` يعتمد على الترتيب (قواعد لاحقة تُعدّل سابقة). لا تعد ترتيب الأقسام.
- **رفع الملفات:** ارفع المجلد كاملًا بنفس الهيكل.

## اختبار سريع بعد كل تعديل
1. افتح الموقع وراقب Console (يجب ألا يظهر خطأ أحمر).
2. غيّر التصنيفات من الشرائح ومن قائمة الهيدر.
3. افتح عنصرًا وجرّب أسهم المعرض والصور المصغرة.
4. افتح `#admin` وتأكد أن الدخول يعمل.
